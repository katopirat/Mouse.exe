# Mouse.exe

![Godot](https://img.shields.io/badge/Godot-4.7-478cbf?logo=godotengine&logoColor=white)

**A 2D top-down puzzle game built with Godot, where physically moving the mouse character simultaneously controls the cursor on a virtual computer screen. There are obstacles like a phone, keyboard etc. There are also ads you have to avoid clicking. You have to usualy hit the green button to open pathways to the finish.

</div>

---

### Controls

| Action | Key |
|:------:|:---:|
| Move | `W` `A` `S` `D` |
| Click | `Left Click` / `Space` |
| Reset | `R` |
